# Документация SEAF Company TA

Этот раздел — пользовательская документация по работе с моделью технической архитектуры.

## Структура документации

| Уровень | Для кого | Что решает |
|---|---|---|
| Простой | Архитектор/аналитик, который начинает работу | Быстро запустить заполнение модели и получить первый рабочий контур |
| Сложный (`advanced`) | Архитектор/владелец модели | Углубленное проектирование, контроль качества, регулярное развитие |
