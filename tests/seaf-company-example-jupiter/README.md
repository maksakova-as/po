# _ООО Юпитер_ - пример цифровой архитектурной модели компании
В данном репозитории представлен пример цифровой архитектурной модели вымышленной компании ООО Юпитер.
Компания входит в Группу компаний "Солнечная система"
Пример реализован на базе SEAF v2 (Sber Enterprise Architecture Framework v2) и предназначен для ознакомления с возможностями фреймворка, иллюстрации применения метамодели описания архитектуры компании.

---

**Дисклеймер**: 

Метамодель SEAF v2 является экспериментальной (beta версия). 
Авторами могут вноситься изменения без предварительного уведомления пользователей. 
Желающие участвовать в развитии метамодели - просьба обращаться к команде SEAF (см. файл [COMMUNITY.md](COMMUNITY.md))

---

## Быстрый старт

1. Установите [SEAF ArchTool](https://gitverse.ru/seafteam/seaf-archtool-core). Для быстрого старта удобнее всего использовать плагин для IDE (например плагин [ArchTool для IDE JetBrains](https://gitverse.ru/seafteam/seaf-archtool-ideplugin-jetbrains))
2. Клонируйте данный репозиторий
3. Скачайте модули метамодели* в папку **\_metamodel_** (* какие модули необходимы для работы данного примера см. в файле **\_metamodel_\packages.yaml**)
4. Откройте проект в IDE
