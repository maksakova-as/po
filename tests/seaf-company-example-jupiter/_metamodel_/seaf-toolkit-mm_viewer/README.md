# Визуализатор метамодели

Пакет предназначен для просмотра метамодели (сущностей) а также модели (объектов=экземпляров сущностей) в SEAF.Archtool\DocHub.

## Использование

1. Подключите пакет к вашей модели. Точка подключения - package.yaml
2. Обновите страницу плагина 
3. Функционал модуля см. в меню "SEAF/Инструменты/MM Viewer"
