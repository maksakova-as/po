# Dataset Speedup Docs

Папка содержит все артефакты по ускорению TA-датасетов:
- план работ;
- базовые замеры;
- результаты по фазам;
- профильные замеры в разных конфигурациях источников;
- targeted-замеры до/после точечных оптимизаций.

Основные файлы:
- `dataset_speedup_plan.md` — основной план и чек-листы фаз.
- `dataset_speedup_baseline.md` — baseline перед оптимизациями.
- `dataset_speedup_phase*_results.md` — результаты по фазам.
- `dataset_speedup_profile_*.md` — профилирование под разные наборы источников.
- `dataset_speedup_targeted_before.md` / `dataset_speedup_targeted_final.md` — точечные замеры до/после.
- `ta_dataset_optimization_plan.md` — дополнительный план оптимизации датасетов.
