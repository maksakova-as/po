# TA menu split

Файлы меню TA разделены по функциональным блокам:

- `services_locations.yaml` — меню сервисов локаций (регион, AZ, ЦОД, офис).
- `services_network.yaml` — меню сетевых сервисов.
- `services_platform.yaml` — меню платформенных сервисов.
- `services_infra.yaml` — меню инфраструктурных сервисов.
- `services_other.yaml` — прочие сервисы.
- `components.yaml` — меню технических компонентов.
