# Генерация схемы R41

В этом каталоге определены датасеты для генерации схемы архитектуры в формате, совместимом с R41 (legacy).

## Логика выбора источника данных

Датасет `seaf.company.ds.ta.schema_r41_plural` строит данные, опираясь на приоритет источников, заданный в конфигурации (`_metamodel_/seaf-company-ta/configs.yaml` или `seaf.configs."seaf.company.ta"`).

### Приоритеты

Конфигурация:
```yaml
data_sources:
  priority:
    - seaf2  # или seaf1
    - seaf1
```

1. **Если приоритет `seaf2` (по умолчанию):**
   - Система ищет сущности SEAF2 (`seaf.company.ta.*`) в `seaf.ds.objects_by_entities`.
   - Если они найдены, они маппятся в легаси-ключи (`seaf.ta.*`) используя карту соответствия (Plural -> Singular).
   - Это позволяет использовать новые данные в старых отчетах/схемах.

2. **Если приоритет `seaf1`:**
   - Система в первую очередь ищет сущности SEAF1 (`seaf.ta.*`) напрямую в `data_lake`.
   - Если они найдены, они используются "как есть" (as is), без маппинга и изменения ключей.
   - Это предотвращает искажение данных при наличии нативного SEAF1 источника.
