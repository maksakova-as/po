# Как настраивать configs.yaml

Файл `../configs.yaml` управляет тем, какие источники данных участвуют в TA-модели и как ведет себя меню/правила.

## 1. Где находится конфигурация

- Путь: `_metamodel_/seaf-company-ta/configs.yaml`.
- Корневой блок: `seaf.configs -> seaf.company.ta`.

## 2. Что именно настраивается

| Блок | Назначение | Когда менять |
|---|---|---|
| `root_menu`, `root_menu_order` | Название и позиция корневого пункта TA в меню | Нужно переименовать/переставить TA-раздел |
| `rules.rules_enabled`, `rules.rules_disabled` | Включение проверок качества и список исключений | Нужно временно отключить/сузить правила |
| `data_sources.profile` | Выбор профиля источников данных | Основной переключатель режима работы модели |
| `data_sources.profiles.*` | Состав источников (`enabled`) и их приоритет (`priority`) по профилю | Нужен новый режим (например, без reverse) |
| `schema_r41_plural.include_reverse` | Участвует ли reverse-слой в общей схеме Р41 | Нужно включать/исключать reverse на схеме |

## 3. Профили источников данных

В текущей конфигурации поддерживаются:

- `seaf2_only` — только seaf2 (самый быстрый и базовый режим);
- `seaf2_seaf1` — seaf2 + seaf1;
- `full_with_reverse` — seaf2 + seaf1 + kadzo + reverse.

Практика:

1. Для начального наполнения и быстрой диагностики используйте `seaf2_only`.
2. Для полного контура интеграций — `full_with_reverse`.

## 4. Как переключить режим

Измените одно поле:

```yaml
seaf.configs:
  seaf.company.ta:
    data_sources:
      profile: seaf2_only
```

После изменения перезапустите сборку/контейнер среды, чтобы конфиг перечитался.

## 5. Если нужен ручной режим без profile

Если `profile` не задан или не найден, используется fallback:

- `data_sources.enabled`
- `data_sources.priority`

То есть можно явно задать источники без профилей.

## 6. Минимальная проверка после изменения

- В нужных реестрах появились/исчезли объекты ожидаемого источника.
- Карточки объектов открываются без ошибок ссылок.
- Для Р41: если меняли `include_reverse`, поведение схемы соответствует ожиданию.
