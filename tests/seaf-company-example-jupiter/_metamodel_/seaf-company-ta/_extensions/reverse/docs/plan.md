# План работ reverse → SEAF2

## Общие правила
- Читаем `Docs/operations_manual.md` перед любыми действиями: только GET-валидация и `docker restart archtool_reverse_seaf2` (ожидание 60 сек).
- Любое выражение проходит через `ta/jsonata_tests` → `python get_jsonata.py ...` → запись результата в `log.md` → перенос в `ta/dataset_parts`.
- `_metamodel_/seaf-company-ta/ta/datasets.yaml` собирается из `dataset_parts/*.yaml`; после обновления валидируем reverse-датасет, merge (`seaf.company.ds.ta.*`), `/core/storage/problems/` и соответствующую UI-страницу.
- Все шаги фиксируем в `plan.md` (таблица ниже) и `log.md`.
