# Метамодель SEAF* Company пакет DA
*SEAF v2 (Sber Enterprise Architecture Framework v2) открытый и развиваемый сообществом экспертов-практиков 
архитектурный фреймворк = набор методов и инструментов, позволяющих управлять корпоративной архитектурой в группе компаний масштаба Сбера*

Модуль расширения метамодели seaf.company, в которм определены элементы домена Архитектура Данных

Чтобы увидеть работу модуля в деле - необходимо его подключить к метамодели конкретного цифрового репозитория,
где планируется описывать архитектурную модель компании.
Для учебных целей можно воспользоваться примером описания архитектурной модели компании Юпитер:
- [внутр. репозиторий Сбера](https://stash.sigma.sbrf.ru/projects/METAECO_DZO/repos/seaf-company-example-jupiter/)
- [репозиторий Группы Сбер (Sberworks)](https://sberworks.ru/bitbucket-ci/scm/kbdzo/seaf-company-example-jupiter.git)


Желающие участвовать в развитии метамодели - просьба обращаться к команде SEAF (см. файл [COMMUNITY.md](COMMUNITY.md))
